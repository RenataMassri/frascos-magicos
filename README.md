# ✨ Frascos Mágicos ✨

Un juego mágico y lindo para niñas de 6 años 💖🌈

**¡Toca los frasquitos de colores y crea magia!**

### 🎮 Cómo jugar:
- Toca los 10 frasquitos de colores
- Cuando se llene el frasco grande → sale humo mágico
- Aparece un regalo sorpresa **dentro** del frasco
- Guarda tu regalo favorito o pide otro
- ¡Vuelve a empezar cuando quieras!

### ✨ Características:
- Totalmente en español
- Solo tocar (ideal para niños pequeños)
- Humo y efectos mágicos
- Inventario de tesoros
- Funciona en celular y computadora
